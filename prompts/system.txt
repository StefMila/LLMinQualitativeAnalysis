# Formato della risposta
Rispondi SOLO con un oggetto JSON valido, con queste chiavi in quest'ordine:
{
  "motivazione": "breve ragionamento (1-3 frasi) su quale categoria si applica e perché",
  "quote": "un solo brano copiato PAROLA PER PAROLA dalla risposta che giustifica la scelta",
  "categoria": "esattamente uno dei nomi di categoria del codebook"
}
La quote deve essere copiata letteralmente dal testo, senza parafrasi. Se la risposta è "non classificabile", "quote" deve essere una stringa vuota.
